TDM22 R13: verification results

All 16 R13 regression groups and the additional four STEP-loading tests passed. The existing solver/UI/CSV/recipe and JMP-to-Python bridge regression suite also passed. References here are synthetic; no experimental chromatogram or sample calibration was supplied.

What caused premature sample output

The supplied run table loaded at 0% B and ramped toward 100% B, while Buffer B was the high-salt buffer. The stored Langmuir affinities were also weak. Native CPA describes ion exchange, so its salt-screening response cannot stand in for HIC binding. R13 uses explicit HIC affinity, initially equilibrated effective load chemistry, and a high-to-low salt demonstration recipe.

Export tests verified the predicted-minus-measured sign and that exported point contributions sum to the reported objective for both objective choices.

Least-squares construction

r[r,j] = predicted_detector_signal[r,j] - reference_detector_signal[r,j]
Eq. 9 objective = sum_r sum_j r[r,j]²
Variables = eligible unlocked fields; all locked fields and recipes fixed.

RAW_SSE is the default. No baseline is inferred by default; no profile normalization or peak alignment is implicit. NORMALIZED_MSE and initial-median baseline correction are explicit options. Bounded residual-vector trust-region least squares follows the lsqnonlin formulation through SciPy. It is a local nonlinear optimizer, not MATLAB's executable.

Scope of verification

Python 3.12.14; NumPy 2.3.5; SciPy 1.17.0. Generated JSL and isolated bridge actions were tested. JMP itself was unavailable, so native JMP rendering/clicking was not executed. The CPA HIC branch is a documented empirical salt-affinity extension with CPA surface competition; the supplied CPA paper establishes IEX rather than this HIC extension.

TDM22 R14: capacity units and feed concentration

The 12 R14 checks and the full existing solver/UI/CSV/recipe/JMP-to-Python bridge regression suite passed.

Input changes

Saturation capacity is entered and stored as qmax_g_L, in g/L of non-mobile stationary phase. Old qmax_mg_ml inputs migrate with factor 1 because 1 mg/mL = 1 g/L. The numerical value and phase-volume basis are preserved; there is no factor of 1000 and no automatic packed-bed conversion. Both competitive Langmuir solvers and the fitted parameter catalog consume the new field. H = qmax × b remains derived.

The process input is now labeled Feed concentration [mg/mL]. Its saved CSV binding is unchanged. Species inlet concentrations are feed concentration multiplied by species mass fraction. A fixed load volume gives loaded mass proportional to feed concentration; fixed load capacity gives load CV = capacity / feed concentration.

Saved unlocked-parameter lists and all selected 1–5 run lists now survive normalization and reload. Testing exposed and corrected a previous defaults-merge bug that could discard these optional fields.

Forward-model verification

Each comparison used synthetic two-species inputs with a 2 mL applied volume. Old and new qmax schemas produced exactly identical UV and column concentration arrays. At the same applied volume, increasing feed concentration from 0.5 to 1 mg/mL doubled the input mass and changed the predicted UV.
